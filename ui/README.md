# EDR Dashboard - Web User Interface

A simple, modern web-based dashboard for monitoring the EDR Sysmon threat detection system.

## Features

- 📊 **Real-time Statistics** - Track total alerts, severity distribution, and last 24-hour events
- 📋 **Alert Management** - Browse, filter, and analyze security alerts by severity 
- 🚫 **Blacklists** - Manage malicious hashes, IPs and domains  

## Installation

### 1. Install Dependencies

```bash
pip install flask
```

### 2. Run the Interface
```bash
python ui/app.py
```
